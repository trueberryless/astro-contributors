# `astro-contributors-docs`

Documentation for the `astro-contributors` Astro components, deployed at [astro-contributors.netlify.app](https://astro-contributors.netlify.app).

## Documentation

Run the documentation locally by running the following command in your terminal:

```shell
pnpm run dev
```

Content can be found in the [`src/content/docs/`](https://github.com/trueberryless/astro-contributors/tree/main/docs/src/content/docs) directory.
