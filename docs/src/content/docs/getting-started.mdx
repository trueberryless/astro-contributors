Prepare your Astro project to use all available components from the `astro-contributors` package.

## Prerequisites

You will need to have an Astro website set up.
If you don't have one yet, you can follow the ["Install and Setup"](https://docs.astro.build/en/install-and-setup/) guide in the Astro docs to create one.

## Installation

`astro-contributors` is an npm package that exports multiple [Astro components](https://docs.astro.build/en/basics/astro-components/). Install the package by running the following command in your terminal:

<Tabs syncKey="pkg">

<TabItem label="npm">

```sh
npm install astro-contributors
```

</TabItem>

<TabItem label="pnpm">

```sh
pnpm add astro-contributors
```

</TabItem>

<TabItem label="Yarn">

```sh
yarn add astro-contributors
```

</TabItem>

</Tabs>

## Usage

The ["Using Components" guide](https://starlight.astro.build/components/using-components/) explains how to use components in MDX and Markdoc.

Check out the [`ContributorList`](/components/contributor-list) and the [`AllContributors`](/components/all-contributors) components, which are exported by this package and can be imported via:

<Preview>

```mdx
import { ContributorList } from "astro-contributors"

<ContributorList githubRepo="trueberryless/astro-contributors" />
```
