:::note
If your repository is **private** or you are hitting rate limits, set the `PUBLIC_GITHUB_TOKEN` environment variable to a [GitHub personal access token](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens) in the environment that runs your Astro build, e.g. your hosting provider's environment variables. If you build in GitHub Actions, store the token as a [secret](https://docs.github.com/en/actions/security-for-github-actions/security-guides/using-secrets-in-github-actions) and pass it to the build step with `env: PUBLIC_GITHUB_TOKEN: ${{ secrets.PUBLIC_GITHUB_TOKEN }}`. If the repository is public, you can skip this step.
:::

## Import

```tsx
import { ContributorList } from "astro-contributors";
```

## Usage

Display the code contributors of a GitHub repository using the `<ContributorList>` component and provide a [`githubRepo`](#githubrepo).

## `<ContributorList>` Props

The `<ContributorList>` component accepts the following props:

### `githubRepo`

**Type**: `${string}/${string}` <br />
**Default**: `"withastro/docs"`

Define the GitHub repository to fetch contributors from in the format `owner/repo`.

### `ignore`

**Type**: `string[]` <br />
**Optional**

An array of GitHub usernames to ignore when fetching contributors.
This feature is very useful if you have a bot account that you don't want to display.

<Preview>

```mdx
import { ContributorList } from "astro-contributors"

<ContributorList githubRepo="trueberryless/astro-contributors" ignore={["autofix-ci[bot]", "github-actions[bot]", "renovate[bot]"]} />
```

<ContributorList slot="preview" githubRepo="trueberryless/astro-contributors" ignore={["autofix-ci[bot]", "github-actions[bot]", "renovate[bot]"]} />

</Preview>

### `focusColor`

**Type**: `string` <br />
**Optional**

The accent color used for the avatar background and focus outlines. This can be any valid CSS color value (Hex, RGB, HSL, etc.).

If not provided, the component will first check for a global CSS variable named `--avatar-focus-color`, then fall back to [Starlight](https://starlight.astro.build)'s `--sl-color-accent`, and finally default to a standard blue.

<Preview>

```mdx
import { ContributorList } from "astro-contributors"

<ContributorList
  githubRepo="trueberryless/astro-contributors"
  focusColor="#ff5733"
/>
```

<ContributorList
  slot="preview"
  githubRepo="trueberryless/astro-contributors"
  focusColor="#ff5733"
/>

</Preview>

You can notice the focus color, when you use keyboard navigation.

### `formatLink`

**Type**: `(username: string) => string` <br />
**Optional**

By default, clicking on an avatar links to the contributor's GitHub profile. You can override this behavior by passing a function to `formatLink`. This function receives the contributor's GitHub username and should return the desired custom URL as a string. 

For example, you can use this to link directly to their commit history in the repository instead of their profile page.

<Preview>

```mdx
import { ContributorList } from "astro-contributors"

<ContributorList
  githubRepo="trueberryless/astro-contributors"
  formatLink={(username) => `https://github.com/trueberryless/astro-contributors/commits?author=${username}`}
/>
```
