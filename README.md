# `astro-contributors`

Astro components to display all contributors to your project.

[![Netlify Status](https://api.netlify.com/api/v1/badges/1c865422-4bef-4dc0-8451-c932c2a47fbc/deploy-status)](https://app.netlify.com/sites/astro-contributors/deploys)

## Documentation

Read the [Astro Contributors docs](https://astro-contributors.netlify.app).

## Package

If you are looking for the Astro components package, you can find it in the [`packages/astro-contributors/`](https://github.com/trueberryless/astro-contributors/tree/main/packages/astro-contributors) directory.

## Project structure

This project uses pnpm workspaces to develop a single Astro components package from the `packages/astro-contributors/` directory. A Starlight documentation site is also available in the `docs/` directory that is also used for testing and demonstrating the Astro components.
